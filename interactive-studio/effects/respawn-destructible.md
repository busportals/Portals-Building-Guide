# Respawn Destructible

## Use Cases

***

* Bringing back destroyed crates or barriers after a timer
* Resetting destructible objects between game rounds
* Respawning breakable targets in a shooting gallery

## Configuration

***

No additional configuration needed. When triggered, the destructible object is respawned at its original location.

## Compatibility

***

| Object Type   | Compatibility |
|---------------|:-------------:|
| Destructible  | ✅ |
