# Vehicle Boost

## Use Cases

***

* Creating boost pads on a race track
* Rewarding players with a speed burst for completing objectives
* Adding nitro-style boost mechanics to vehicle gameplay

## Configuration

***

| Setting        | Permitted Values | Description                                                  |
| -------------- | ---------------- | ------------------------------------------------------------ |
| Duration       | Float            | How long the boost lasts in seconds.                         |
| Speed of Boost | Float            | The boost speed applied to the vehicle.                      |
| Ramp Up Time   | Float            | Time in seconds to reach full boost speed.                   |
| Ramp Down Time | Float            | Time in seconds to decelerate back to normal speed.          |

## Compatibility

***

| Object Type | Compatibility |
|-------------|:-------------:|
| Vehicle | ✅ |
