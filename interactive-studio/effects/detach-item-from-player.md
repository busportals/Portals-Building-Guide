# Detach Item From Player

## Use Cases

***

* Remove an item that was previously attached to a player
* Dropping or releasing held objects during gameplay
* Clearing attached equipment when switching states or zones

## Configuration

***

| Setting | Permitted Values | Description |
| ------- | ---------------- | ----------- |
| Item    | Object reference | The item to detach from the player. |
