# Start Speaking

## Use Cases

***

* Playing the NPC's speaking animation during a dialogue sequence
* Creating the appearance of an NPC talking to the player
* Syncing NPC mouth movement with audio or dialogue effects

## Configuration

***

No additional configuration needed. When triggered, the NPC begins its speaking animation.

{% hint style="info" %}
Use the [Stop Speaking](stop-speaking.md) effect to end the speaking animation.
{% endhint %}
