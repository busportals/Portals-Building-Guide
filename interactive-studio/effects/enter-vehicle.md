# Enter Vehicle

## Use Cases

***

* Placing a player in a vehicle when they interact with it
* Automatically mounting a player to a vehicle at game start
* Entering a vehicle as part of a scripted event

## Configuration

***

No additional configuration needed. This effect must be set up on the vehicle object itself. When triggered, the player enters that vehicle.

## Compatibility

***

| Object Type | Compatibility |
|-------------|:-------------:|
| Vehicle | ✅ |
