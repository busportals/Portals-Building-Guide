# Deactivate Trigger Zone

## Use Cases

***

* Disabling a one-time checkpoint so it can only be triggered once
* Turning off hazard zones when a game phase ends
* Preventing a trigger from firing again until reactivated

## Configuration

***

No additional configuration needed. This effect disables the trigger zone it is applied to, preventing it from firing until reactivated.

{% hint style="info" %}
Use [Activate Trigger Zone](activate-trigger-zone.md) to re-enable the trigger zone.
{% endhint %}
