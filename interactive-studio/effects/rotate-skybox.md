# Rotate Skybox

## Use Cases

***

* Creating a day-night transition by rotating the skybox over time
* Adding dynamic sky movement to make environments feel alive
* Shifting the sky to match a scene change or story beat

## Configuration

***

| Setting  | Permitted Values | Description                                          |
| -------- | ---------------- | ---------------------------------------------------- |
| Rotation | Float            | The target rotation in degrees.                      |
| Duration | Float            | How long the rotation takes in seconds.              |
