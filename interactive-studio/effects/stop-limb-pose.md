# Stop Limb Pose

## Use Cases

***

* Releasing a limb after an aiming or holding interaction ends
* Returning all limbs to default animation when exiting a gameplay mode
* Resetting a specific limb pose when switching weapons or tools

## Configuration

***

| Setting | Permitted Values                         | Description                                                                                   |
| ------- | ---------------------------------------- | --------------------------------------------------------------------------------------------- |
| Limb    | Right Arm, Left Arm, Right Leg, Left Leg | Which limb to release. If not specified, all active limb poses are stopped.                   |
