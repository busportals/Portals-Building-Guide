# Activate Trigger Zone

## Use Cases

***

* Re-enabling a checkpoint zone after a game resets
* Activating a trigger zone only after a prerequisite task is completed
* Turning on hazard zones during specific game phases

## Configuration

***

No additional configuration needed. This effect re-enables the trigger zone it is applied to, allowing it to fire its triggers again.

{% hint style="info" %}
Use [Deactivate Trigger Zone](deactivate-trigger-zone.md) to disable a trigger zone.
{% endhint %}
