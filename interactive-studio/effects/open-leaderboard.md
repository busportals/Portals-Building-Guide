# Open Leaderboard

## Use Cases

***

* Displaying the leaderboard at the end of a round or race
* Allowing players to check rankings by interacting with an object
* Showing scores after a timed challenge completes

## Configuration

***

| Setting          | Permitted Values | Description                                                          |
| ---------------- | ---------------- | -------------------------------------------------------------------- |
| Leaderboard Name | String           | The name of the leaderboard to display.                              |
